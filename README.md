# مكتب التسليم الفني — مجمع الأميرات 2 (النظام الجديد)

نظام متابعة دور قيد التسليم والمراجعات والدور المسلّمة.
- البيانات من ملفات Google Sheets (الموقف الاسبوعي، تواريخ الاستلام، موقف المقاولين).
- قاعدة بيانات منفصلة: Firebase `amirat2-delivery` (Realtime Database + تسجيل دخول).
- النظام الحالي (Netlify) ما يتغيّر — النسخ منه قراءة فقط من الإعدادات.
